# Arm D conformance report — a synthetic grid

Generated by `rzp-armd`. Computed, not written by hand.

> **Arm D is a pre-registered, same-author synthetic conformance corpus
> scored against author-declared labels.**
>
> **Its 90-row confusion matrix is exact for that finite grid, but it is
> not independently labelled or policy-blind and does not establish
> transferable recall, precision, or false-positive cost.**
>
> Read `study/ASSESSMENT-armD.md` before quoting any figure below.

## Scope

A conformance check of a **deterministic verifier** on a constructed grid of
90 refund requests.

**Scored against author-declared labels.** Each decision is compared to the
`label` field in `requests.json`. `rzp-armd` reads that field and nothing
else: it does not read `intent_text` and derives no label of its own. The
labels, the corpus generator and the policy have one author.

**Not agent traffic.** The requests are constructed, so nothing here says
how often an agent would make one. Arm C asked that question, failed, and
that failure stands: see `PRELABEL-FINDING-armC.md`.

**Policy frozen before the corpus existed.** `fb87b12` (2026-08-30). The
implementation cannot have been fitted to data that did not exist, and the
commits are checkable. That is all the date establishes — it does not blind
the author, who knew the decision rule while building the corpus.

**No model is called; nothing is random; the corpus is scored once.**

## 2. Precision is base-rate dependent; recall is not

Prediction D5, recorded before scoring. The corpus is 60% positive by
construction, and that is a design choice, not an observed rate. Precision
moves with it. **Recall does not** — it is computed only over positives.

Holding the measured rates fixed (TPR 1.000, FPR 0.472), precision at other
base rates would be:

| out-of-intent share | precision |
|---|---|
| 60% (this corpus) | 0.761 |
| 25% | 0.414 |
| 10% | 0.190 |
| 5% | 0.100 |
| 1% | 0.021 |

None of these figures transfers. The class balance is a design choice and
the labels are the author's, so the row that would apply to real traffic is
not in this table.

## 4. What this does not establish

- Not a rate of agent misbehaviour. The requests are constructed.
- Not a metric result. The labels are author-declared, not independent.
- Not merchant traffic, and not a fraud rate.
- Precision is a property of this corpus's class balance.
- The false-positive cost is a property of the intent→mandate compiler as
  much as of the guard. `coverage=under` cells were built so the mandate
  under-expresses the intent; refusing there is correct enforcement of an
  incomplete authorization.
- One author designed the dimensions. Enumeration removes selection bias
  within the grid, not the grid's blind spots.
